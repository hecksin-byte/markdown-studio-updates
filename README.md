# Markdown Studio 업데이트

Markdown Studio 앱이 새 버전을 확인하고 내려받는 공개 저장소입니다.

- `stable.json`: 개발자 서명이 들어간 최신 버전 안내. 앱이 시작할 때 읽습니다.
- `MarkdownStudio-<새 버전>-Update-from-<이전 버전>.exe`: 바뀐 파일만 담은 작은 업데이트.

앱은 안내의 서명과 파일의 SHA-256을 확인한 뒤에만 설치합니다. 이 저장소의 파일을 직접 받아 실행할 필요는 없습니다. 앱의 **프로그램 정보 → 업데이트 확인**을 사용하세요.
